# 🍽️ Food Review Website

This is a simple Food Review Website developed as part of a non-credit course using HTML, CSS, and JavaScript.

## 📌 Project Overview
The website allows users to explore food places, submit reviews, and rate their experiences. It focuses on creating an interactive and user friendly frontend interface.

## 🚀 Features
- Add and view food reviews
- Rating system for restaurants
- Responsive design
- Dynamic content using JavaScript
- Basic "Verify you are human" interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
